# Prompting from First Principles

An 8-hour interactive course on prompt engineering for early college students. It covers how language models process words, context and input quality, step-by-step structure, cutting filler, and systematic debugging. Every topic is taught through 20 examples from student life.

The whole course is one self-contained file: `index.html`. It needs no build step, server or database.

## Put it live on GitHub Pages (about 5 minutes)

1. Sign in to GitHub and click **New repository**.
2. Name it, for example `prompting-first-principles`. Set it to **Public** and click **Create repository**.
3. On the new repository page, click **uploading an existing file**.
4. Drag in `index.html`, `README.md` and `.nojekyll`, then click **Commit changes**.
   - If your computer hides `.nojekyll`, skip it. The site works without it.
   - **Copy-paste instead of upload:** click **Add file → Create new file**, name it `index.html`, paste the full contents of `index.html`, and click **Commit changes**.
5. Go to **Settings → Pages**. Under **Build and deployment**, set **Source** to *Deploy from a branch*. Set **Branch** to `main` and the folder to `/ (root)`, then click **Save**.
6. Wait one to two minutes, then refresh the Pages settings. Your link appears at the top:
   `https://<your-username>.github.io/prompting-first-principles/`

## What's inside

| Page | What it does |
|---|---|
| Course overview | The four truths, the six-step build, and the course at a glance |
| Session plan | The 09:00–17:00 timetable, learning outcomes, delivery tips and the instructor prep checklist |
| 20 student examples | Each example as an analogy prompt next to a first-principles prompt, with a filter |
| M0–M7 | Each module has four tabs: Trainee notes, Instructor notes (Instructor mode only), Try it and Check |
| Final assessment | 20 timed questions drawn from a bank of 27. Answers resume after a refresh |
| Certification | Three certificate levels, the rubric and policies. Generates a certificate image students can save |

## Good to know

- **Saved progress stays in each person's browser.** Check scores, drafts and exam results are stored in that browser only, so they don't sync across devices and aren't an official record. Instructors record official scores separately.
- **Trainee and Instructor modes** are switched with the toggle in the top bar.
- **Internet access** is only needed for the Google Fonts typefaces. Without it, the page uses system fonts.
- **To edit content**, open `index.html` in any text editor. Course content sits near the top of the file in `EXAMPLES`, `MODULES`, `FINAL_BANK` and `RUBRIC`. Commit the change and the site updates in about a minute.
